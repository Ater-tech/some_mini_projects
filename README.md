# Flutter Mini Lessons & Practice Projects

## About This Repository

This repository contains a collection of Flutter mini lessons and practical applications created to improve my Flutter and Dart development skills.

The main goal of this project is to learn Flutter widgets, understand their behavior, and apply them in small, practical applications.

## Mini Lessons

The repository includes multiple small applications and practical examples covering different Flutter concepts and widgets.

Topics include:

- Text and Text Containers
- Buttons and Interactive Widgets
- Images and Image.network
- Image.asset and Image Handling
- Layout Widgets
- Rows and Columns
- Containers and Decorations
- Lists and Grid Views
- User Interaction
- Basic Navigation
- UI Design and Styling
- Other commonly used Flutter widgets

Each mini application focuses on a particular widget or concept and demonstrates how it works in practice.

## Pokémon App

This repository also includes a Pokémon application developed using a ready-to-use public API.

Key features and concepts:

- Fetching data from an external API
- Working with JSON responses
- Displaying Pokémon information
- Loading images from network sources
- Building dynamic UI components
- Practicing API integration in Flutter

## Technologies Used

- Flutter
- Dart
- REST API
- JSON
- HTTP Requests
- Flutter Widgets

## Purpose

This project represents my practical learning journey as a Flutter Developer.

It demonstrates my progress from basic Flutter widgets to API-integrated applications and more interactive user interfaces.
